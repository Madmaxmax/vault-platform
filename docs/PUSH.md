# Публикация на GitHub

1. Создать **пустой** репозиторий на GitHub, без автоматической инициализации README.
2. В распакованном каталоге:

```bash
git log --format='%h %ad %an %s' --date=iso
# убедитесь, что автор и даты отражают действительные сведения
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

История из архива содержит несколько **настоящих коммитов одного сеанса подготовки**. Даты не подделывались и не распределялись искусственно по неделям. Для получения реальной истории на протяжении следующих недель создавайте PR и коммиты по `ROADMAP.md` в момент выполнения каждой задачи.

Ни один коммит в демонстрационном архиве не подтверждает персональную работу DevOps или DevSecOps. Заменяйте автора только при настоящем авторстве, не переписывайте даты ради отчётности.
