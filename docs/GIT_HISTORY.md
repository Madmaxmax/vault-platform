# Реконструкция истории Git

История репозитория восстановлена по учебному календарному плану этапов с сентября по ноябрь 2026 года. Даты AuthorDate и CommitDate в перечисленных ниже коммитах **назначены при реконструкции** и не являются исходными временными метками создания файлов или первоначальных коммитов.

Первоначальная сборка репозитория и проверочные коммиты были оформлены 23–24 ноября 2026 года. При реконструкции сохранены дерево файлов, содержание каждого коммита, связи веток `main`, `devops`, `devsecops` и сообщения коммитов. Хеши изменены вследствие переписывания метаданных.

Для подтверждения реальных дат выполнения задач используйте журнал задач, переписку, исходные файлы, историю удалённых репозиториев и PR. Этот график сам по себе не служит доказательством дат разработки.
